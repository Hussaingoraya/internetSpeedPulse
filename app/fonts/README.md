The WOFF2 is subset using fontTools to Latin U+0000–024F, punctuation U+2000–206F, currency U+20A0–20CF, arrows U+2190–21FF and U+2212. Variable weight support is retained. Other scripts use system fallback fonts. Next.js serves and preloads the font locally; no font provider request is needed at runtime.
